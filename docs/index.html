Got Questions?

Frequently Asked Questions

How many languages does Owlio support?

Owlio supports over 100 languages worldwide. The multilingual Whisper models recognize 100 global languages (including English, Spanish, French, German, Japanese, Korean, Arabic, Russian, and Chinese) with automatic language detection. Additionally, Bodhan Flex provides deep coverage for 27 regional Indic languages and dialects (including Bhojpuri, Odia, Maithili, Konkani, Haryanvi, and Chhattisgarhi), with optional Roman Hinglish conversion.

Do I need to install Python or external packages manually?

No. The Windows installer sets up the full application. Owlio's guided setup downloads its own private, isolated Python runtime and speech model packages automatically.

Does Owlio send my voice or text to external servers?

Not when using local speech models. Speech recognition runs directly on your computer's CPU or NVIDIA GPU. If you choose cloud speech providers (such as Groq) or AI rewrite features (such as Gemini), only the specific audio or text segment for that action is sent using your configuration.

Can I use Owlio completely offline?

Yes. Once your local speech model is downloaded and your account access has completed its daily check, local dictation functions offline without internet connectivity.

Is Owlio free and open-source?

Yes. The desktop source code is released under the MIT license on GitHub. The official app is free to use with sign-in, acceptance of terms, and disclosed basic reliability usage reporting.
