# Owlio 1.0.10

Simplifies speech setup and text processing:

- Local models perform native transcription only. Flex ignores legacy output preferences; Whisper Hinglish uses Hindi decoding rather than English decoding with Roman Hindi prompt examples. Removed the local script selector and unused IndicXlit experiments. Gemini remains the only explicit Hindi-to-Roman conversion path, and English-only input skips conversion.
- One model choice determines required libraries automatically. Hardware/package overrides, component diagnostics, storage, custom imports, punctuation overrides and custom writing rules live under Advanced.
- One independent Writing AI connection serves AI cleanup, selected-text voice rewrites and meeting summaries. Changing speech provider does not reroute writing operations. Fresh profiles use Basic cleanup, Writing AI off and voice rewrites disabled.
- Save settings applies pending preferences across settings pages, including speech/Ollama models and appearance. Downloads, setup/repair, storage operations and explicit rule/dictionary record actions remain immediate operations.
- AI controls require credentials or a reachable installed Ollama model. Model selections require downloaded weights. Flex setup uses the supplied access token, verifies dependencies, and exposes progress/cancellation in the model card.
- Existing settings retain their keys, model, language and shortcut; removed local script preferences are discarded. Legacy local Auto cleanup migrates to Basic rather than assuming Ollama is available. Existing explicit Gemini/cloud cleanup migrates to the independent Writing AI connection.
