# Owlio 1.0.11

Adds multilingual Whisper dictation to the existing spoken-language picker. Select a language or Detect automatically under Speech & models, then Save settings. Standard multilingual Whisper models expose 99 language codes; local large-v3/turbo and the configured Groq v3 model additionally expose Cantonese. Hindi-English speech remains available as Hinglish. Outputs retain their original language and script.

The shared language catalogue is based on [OpenAI Whisper's tokenizer](https://github.com/openai/whisper/blob/main/whisper/tokenizer.py). Model compatibility is checked before saving: Bodhan Flex retains its current English/Hindi/Hinglish integration, while custom Whisper checkpoints may have narrower coverage than the standard models. Unsupported selections remain visible with guidance until the user chooses a compatible model/language; they are not silently changed.

Automatic detection omits a forced language hint on local and cloud requests. The bundled server maps omitted/auto language to automatic detection. Language names appear correctly in the dictation summary, and custom writing rules can target the expanded language list.

Gemini Hindi conversion now runs only for explicit Hindi or Hinglish. Automatic detection and other language selections skip it, protecting Marathi, Nepali and other Devanagari languages from Hindi transliteration. AI cleanup checks actual Unicode letters before applying Latin-only instructions, preserving Tamil, Arabic, Japanese and other scripts.

Validation: type checking/build, 118 JavaScript tests, 19 Python tests, multilingual settings/navigation and first-run UI checks passed. Packaged upgrade and fresh-profile ASAR/helper checks passed, including saving Tamil through the shipped preload/main/settings path. Fresh-profile tests use an offscreen harness; native first-launch visibility and running the installer remain unverified. Transport/script preservation tests use synthetic transcripts and model stubs; no live accuracy benchmark was performed across all languages. Automatic detection does not guarantee reliable recognition of arbitrary language switching within a recording.
