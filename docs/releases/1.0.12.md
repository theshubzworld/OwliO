# Owlio 1.0.12

Choosing a spoken language now selects a compatible local speech model. Owlio keeps a compatible current model, otherwise prefers a compatible downloaded model. If a download is needed, it selects Whisper small for its language set, turbo for Cantonese, or Flex for additional Indic languages and shows the download/setup action. Settings remain staged until saved; downloads require an explicit action.

The language matrix was checked against official model cards and Whisper's tokenizer: multilingual Whisper through large-v2 has 99 languages, large-v3/turbo has 100, Trelis Hinglish documents Hindi/English, and Flex documents 27. All 27 Flex languages now pass through Owlio's native-transcription adapter. English-only `.en` checkpoints are restricted to English. Unknown custom checkpoints require declared language metadata for automatic selection, and their coverage is otherwise marked unverified. [Sources and complete coverage report](../model-evaluations/language-coverage.md).

First-run setup receives the selected language and model together. Main-process and server checks reject unsupported known combinations before activation or inference. Transformers English-only models omit incompatible multilingual generation arguments. Model details show declared language coverage. Local transliteration remains removed; Gemini Hindi conversion is still limited to explicitly selected Hindi/Hinglish.

Compatibility defaults are not per-language accuracy rankings. Validation uses mocked inference and synthetic text; no live accuracy benchmark was performed across every language. Downloaded model weights and the installed application are not replaced by building this release.

Validation: type checking/build, 122 JavaScript tests, 25 Python tests, multilingual settings/navigation and first-run UI checks passed. Packaged upgrade and fresh-profile ASAR/helper checks passed, including the shipped coverage matrix, downloaded-model reuse and saving Tamil through the preload/main/settings path. The fresh-profile harness is offscreen; native first-launch visibility and running the NSIS installer remain unverified.

Installer: `release-artifacts/1.0.12/Owlio-Setup-1.0.12.exe`. The local installer is unsigned and ignored by Git. The installed application was not replaced, and no GitHub release was published.
