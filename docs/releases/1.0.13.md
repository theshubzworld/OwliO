# Owlio 1.0.13

Adds **General settings → Startup → Start Owlio when I sign in to Windows**. Startup is off by default and applies with Save settings. The installed Windows app registers its executable and respects startup changes made in Windows settings. After setup, the dashboard starts minimized with the floating bar available. No recording starts automatically.

Registration is verified before saving preferences; failed preference writes restore the previous Windows registration. Development Electron processes cannot register themselves. A duplicate startup launch does not bring the existing dashboard forward. The installer preserves the preference during upgrades and removes the entry during full uninstall.


Validation: 128 JavaScript tests, type checking/build, isolated settings navigation and first-run checks passed. Packaged upgrade and fresh-profile ASAR/helper checks passed, including the startup IPC path and rejection of development executable registration. Native registration is covered with mocks; tests do not change this Windows account's startup configuration. Actual sign-out/restart and installer/uninstaller execution have not been tested.

The local unsigned installer is built separately; the installed app has not been replaced and no GitHub release has been published.
