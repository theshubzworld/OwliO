# Owlio 1.0.17

## Highlights

- Refreshes the Owlio workspace and dashboard.
- Adds account access with versioned Terms of Use and Privacy Notice, plus required basic usage reporting for the official app.
- Uses Owlio's new preferences file and does not import settings or history from previous profiles. Existing local data remains in its previous file and is not loaded by this version.

## Requirements

- Windows x64
- Owlio account and acceptance of the current legal documents
- Required basic usage reporting
