# Owlio 1.0.18

## Highlights

- Offline speech pipeline hardening: eliminates Whisper prompt echo on silent or short audio segments.
- Token repetition loop mitigation: enforces decoder repetition penalty and disabled previous text conditioning to prevent trailing loops.
- Self-contained rule-based disfluency cleaner: strips speech fillers (e.g. `uh`, `um`, `umm`, `अं`, `उम्`) and cleans accidental stuttering across both Latin Hinglish and Devanagari Hindi without requiring external LLM servers.
- Automatic fallback and speech server resilience improvements.

## Requirements

- Windows x64
- Owlio account and acceptance of the current legal documents
- Required basic usage reporting
