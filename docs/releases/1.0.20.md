# Owlio 1.0.20

Adds Underdog Bark 3.0 Pro for English dictation and Hugging Face imports for compatible Transformers Parakeet TDT checkpoints. Whisper and Bodhan Flex remain supported. Model setup verifies dependencies in a separate runtime before connecting it. Long recordings use pause-aware chunks and timed overlap.

Validation: full Windows build and packaging, 167 JavaScript tests, 42 Python tests, Electron first-run/settings checks, real Bark CPU/GPU transcription, and existing Whisper/Bodhan GPU transcription checks. Packaged version and Bark backend files were inspected. The installer was not installed and no GitHub release or website deployment was performed.
