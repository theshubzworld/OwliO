# Owlio 1.0.23

First-run local speech setup now recommends Whisper Base for multilingual everyday dictation and Bark 3.0 Pro for English-only recognition. The chooser keeps other models available and explains language coverage, download size, setup and hardware tradeoffs, with links to model cards. English is the default for new profiles; existing language preferences are preserved.

Windows startup settings now verify Owlio's actual launch entry. A startup-setting error no longer discards unrelated settings from the same save.

Validation: 172 automated tests, TypeScript checks, renderer build, Electron first-run and settings checks, and Windows x64 installer packaging.

Installer: Owlio-Setup-1.0.23.exe.
