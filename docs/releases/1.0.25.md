# Owlio 1.0.25

Guest mode: Owlio works with no account and no sign-in. Guests get every local feature and send no usage data. Signing in is optional; signed-in accounts report basic usage counts, and signing out returns the app to guest mode. Guests cannot open the owner dashboard.

The Terms of Use and Privacy Notice (version 2026-10-26) now describe guest mode and optional accounts. Signed-in users are asked to accept the new versions once.

The installer now includes LICENSE.txt and THIRD-PARTY-NOTICES.txt, and the Apache-2.0 license text for the bundled Bodhan Flex inference code. 1.0.24 was built but not published; its changes are included here.

Validation: 172 automated tests, TypeScript checks, renderer build, and Windows x64 installer packaging.

Installer: Owlio-Setup-1.0.25.exe.
