# Owlio 1.0.27

Style options now work as described, or say clearly what they need.

Technical tone only affects code editors and terminals. It used to remove capitals and final periods in every app, including email and chat; other apps now get normal punctuation. More code apps are recognized, including Antigravity, Zed, Kiro, Trae, JetBrains IDEs, Android Studio, Sublime Text, Notepad++ and more terminals.

Spellings you accept from your corrections now fix future dictations without Gemini, the same way Word book spellings do. Word book spellings win when both match.

The tone picker can be changed without AI cleanup; without Gemini, tone sets sentence endings only. Tone wording, list organization and writing rules are labeled "Needs Gemini".

Validation: 176 automated tests, TypeScript checks, renderer build, an Electron walkthrough including the Style page without Gemini, and Windows x64 installer packaging.

Installer: Owlio-Setup-1.0.27.exe.
