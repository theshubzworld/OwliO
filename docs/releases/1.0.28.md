# Owlio 1.0.28

Added an optional Hugging Face API token field for private or gated custom speech model URLs.

Under **Speech & models → Advanced models**, an optional **Hugging Face API token** password input now appears alongside the **Custom Hugging Face model URL** field (`#huggingface-model-url`). When provided, the token is validated (`hf_...`), passed in memory to the local speech server's `/v1/models/import` flow for repository inspection and weight download, redacted from error messages, and never saved to disk or settings.

Validation: 176 automated JS tests, 27 Python speech server/model tests, TypeScript checks, renderer build, and Windows x64 installer packaging.
